# Dydah Personal Shopper

Responsive English and Kiswahili business website for Dydah Personal Shopper in Arusha, Tanzania.

## Run locally

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Vite prints a local URL (normally `http://localhost:5173`).

## Build and preview

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. Deploy that directory to a static host such as Vercel or Netlify, or connect the repository and use `npm run build` as the build command and `dist` as the output directory.

## Business settings

Edit `src/config/business.ts` to update the WhatsApp number, displayed phone, Instagram profile, or business location. WhatsApp URLs are generated by `src/lib/whatsapp.ts`; all order and contact links use that shared helper. The configured number is the one provided for Dydah (`+255 759 164 099`).

Shopping and delivery fees are intentionally marked “To be confirmed” until the business supplies actual prices. Customer reviews are not fabricated; the reviews section explains that genuine feedback will be added only with customer permission.

## Project structure

- `src/App.tsx` — page sections, multi-product order form, and contact flow.
- `src/components/` — reusable header and footer.
- `src/data/translations.ts` — English and Kiswahili site copy.
- `src/config/business.ts` — central business contact configuration.
- `src/lib/whatsapp.ts` — shared `wa.me` URL builder.
- `src/assets/` — optimized local copies of supplied market, grocery and fashion photos.
- `src/styles.css` — responsive visual system and layout rules.
